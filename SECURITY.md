# Security policy

This repository is an educational API starter. It is **not audited**, does not custody funds, and does not implement wallets, token swaps, liquidity pools, or on-chain settlement.

Do not send real funds, private keys, seed phrases, or production credentials to this project. If you discover a security issue in the code, open a private GitHub security report when available; otherwise open a minimal public issue without including secrets or exploitable details.
