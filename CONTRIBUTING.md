# Contributing

Thanks for helping improve this starter project.

## Local setup

Use Node.js 18 or newer:

```bash
npm install
npm test
npm start
```

The server listens on port `3000` by default. Set `PORT` to use another local port. Verify it with `curl http://localhost:3000/health`.

## Pull requests

Keep pull requests focused, explain the user-facing change, and include or update tests. Do not add real private keys, wallet secrets, production endpoints, or claims that a feature is audited. DeFi functionality must be designed and reviewed separately before it is presented as implemented.
